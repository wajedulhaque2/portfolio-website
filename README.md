# Wajedul Haque Portfolio Website

Source repository for my personal portfolio website.

The site presents engineering, data analytics, machine learning, quantitative finance, design, sustainability and project-management work completed during my UCL Mechanical Engineering degree and through personal projects.

## Structure

- `index.html` — current portfolio website
- Project workbooks, reports and supporting documentation remain in their dedicated GitHub repositories and are linked from the site rather than duplicated here.

## Deployment

The production website is hosted on Netlify. The intended deployment workflow is GitHub `main` → Netlify production.
